# Fakemon project

The active references are the three phone-designed concept sheets supplied by the user: **Voltuff**, **Embernewt**, and **Sedgling** families. They replace the earlier feline Electric/Fighting concept.

- [Current species catalog](designs-2026-09/SPECIES.md)
- [Machine-readable confirmed information](designs-2026-09/species.json)
- [Moveset reference analysis and Voltuff analogues](designs-2026-09/moves-research/README.md)
- [Installed graphics and animated previews](designs-2026-09/graphics/README.md)
- [Graphics requirements and workflow](GRAPHICS-SPEC.md)

There are 11 distinct named visual designs. The eventual number of engine species/form records remains undecided because Pyrovaran/Rimevaran switching will be represented by a future mechanic.

Native graphics for all 11 designs are installed under `data/graphics/sprites/<name>/`. All 66 indexed PNGs pass format checks and the engine graphics converters. Species registration and in-game testing remain pending; no unknown gameplay data has been filled in. The original enlarged reference sheets remain under `designs-2026-09/graphics/drafts`.

The superseded feline work is retained only in [archive/retired-electric-feline](archive/retired-electric-feline/README.md); do not use its anatomy, palette, or approvals for the new line.
